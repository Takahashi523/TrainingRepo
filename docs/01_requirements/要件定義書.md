## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | 国内SES向け 人材・案件マッチングシステム開発 |
| 目的 | SES営業・コーディネーターの業務効率を劇的に向上させるマッチング支援ツールの開発 |
| 開発期間 | 4ヶ月（90人日） |
| 開発開始日 | 2026/04/01 |
| リリース目標日 | 2026/06/30 |

### 1.1 背景・目的

本システムは求職者向けの汎用求人サイトではなく、SES営業・コーディネーターが社内業務で使用する**B2B向け営業支援ツール**である。

現状の課題として、汎用求人サイトは以下の点でSES業務に不向きである。
- 求職者本人が操作することを前提とした設計になっている
- 外国籍判定・在留資格管理など不要な機能が多い
- SES特有の商習慣（商流・単価レンジ・工程経験）に対応していない

本システムはこれらの課題を解決し、4ヶ月で実務レベルの価値を創出することを目標とする。

## 2. システムコンセプト

### 2.1 基本方針

- **対象ユーザー**：SES営業担当・コーディネーター（社内利用）
- **前提**：日本人SES・国内商流に特化
- **方針**：余分な機能を削ぎ落とした特化型システム

### 2.2 4つの柱

| 柱 | 概要 |
|---|---|
| 1. 人材管理 | 経歴・希望条件のDB管理 |
| 2. 案件管理 | 国内SES要件準拠のDB管理 |
| 3. マッチング＆AI | ルールベーススコアリング＋AI推薦理由生成 |
| 4. 進捗管理 | 提案〜参画までのパイプライン管理 |

### 5.3 マッチング機能

#### 5.3.1 マッチング実行方式（QA#51・QA#35確定）

- **実行方向**：人材側から案件を探す方向のみ（案件→人材の逆引きは対象外）
- **実行単位**：人材1名に対して複数案件のスコアを算出
- **実行可能画面**：「人材一覧」と「人材詳細」の2箇所（※QA#51未確定：画面の確認待ち）

#### 5.3.2 マッチング実行トリガー（QA#32確定）

| トリガー | 要否 |
|---|---|
| 手動実行（人材一覧・人材詳細画面から） | **マスト** |
| 案件登録時の自動実行 | 可能であれば実装 |

#### 5.3.3 スコアリングロジック

100点満点のルールベーススコアリングにより、人材と案件の適合度を算出する。

| 評価項目 | 配点 |
|---|---|
| 必須スキル一致 | 30点 |
| 工程経験一致 | 20点 |
| 尚可スキル一致 | 10点 |
| 単価一致 | 10点 |
| 勤務地／通勤条件一致 | 10点 |
| 勤務形態一致 | 10点 |
| 稼働開始時期一致 | 5点 |
| 顧客折衝／人物要件一致 | 5点 |
| **合計** | **100点** |

> **QA#31確認中**：スコアリングの配点は現場担当確認中。確定次第更新する。

#### 5.3.4 マッチングスコアの保持方式（QA#45確定）

**オンデマンド計算（DBへの保存なし）** を採用する。  
案件クローズ・人材スキル更新時のスコア陳腐化を回避するため、都度計算方式とする。

#### 5.3.5 ランク定義

| ランク | スコア | 意味 |
|---|---|---|
| A | 80点以上 | 即提案レベル |
| B | 65〜79点 | 検討可能 |
| C | 50〜64点 | 条件交渉次第 |
| D | 49点以下 | 見送り推奨 |

#### 5.3.6 AI補助機能

評価はルールベースで行い、AIは提案の手間を削減するアシスタントとして機能する。

| 機能 | 内容 |
|---|---|
| 推薦理由の自動生成 | なぜこの人材が案件に合うのかを言語化 |
| 不足条件の説明 | 満たしていない要件のピックアップ |
| 職務経歴の要約 | 長い経歴書から強みとスキルタグを抽出 |

**AI処理の通信方式（QA#47確定）**：同期通信（処理完了まで画面で待機する方式）を採用する。

> **QA#34未確定**：AI出力の文字数・フォーマット要件は回答待ち。
> **QA#33未確定**：マッチング結果の表示件数上限は回答待ち。

### 5.4 進捗管理

#### 5.4.1 パイプライン表示（QA#1・QA#5確定）

- **カンバン画面**：「営業担当者が担当している人材×案件の組み合わせ」を1カード1件として一覧表示する。
- **表示分離**：現在進行中のカードと、完了（見送り・保留等）のカードは別画面または別タブで確認できるようにする。

#### 5.4.2 進捗ステータス定義（QA#2確定）

| # | ステータス |
|---|---|

| 2 | 求職者応募済み |
| 3 | 応募中 |
| 4 | 一次調整中 |
| 5 | 一次待ち |
| 6 | 一次結果待ち |
| 7 | 最終調整中 |
| 8 | 最終待ち |
| 9 | 最終結果待ち |
| 10 | オファー |
| 11 | アサイン承諾待ち |
| 12 | 成約 |

**終了ステータス（4種）：**

| # | ステータス |
|---|---|
| 1 | 不成立 |
| 2 | 募集終了 |
| 3 | アサイン辞退 |
| 4 | 辞退 |

> **QA#62未確定**：各進行中ステータスの業務上の定義（いつ・どの状態を指すか）は回答待ち。

（人材詳細・案件詳細画面からの手動追加は不要）
