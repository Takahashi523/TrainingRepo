# リードエンジニア向け 初期環境構築手順書

> 対象者：初回セットアップ担当者 
> 実施タイミング：プロジェクト開始時に**1回だけ**実施する  
> この作業が完了してから、メンバーへリポジトリを共有してください

---

## 前提条件

以下をホスト OS にインストールしてください。

| ツール | 用途 | インストール先 |
|---|---|---|
| Docker Desktop | コンテナ実行基盤 | https://www.docker.com/products/docker-desktop/ |
| Git | バージョン管理 | https://git-scm.com/ |

## 1. GitHub リポジトリの作成

1. GitHub にログインし、新規リポジトリを作成する
   - リポジトリ名：`TrainingRepo`
   - Visibility：`Private`
   - README・.gitignore は追加しない（後で追加するため）

---

## 2. ZIP ファイルの展開とリポジトリ初期化

```bash
unzip ses-matching-init.zip
mv ses-matching TrainingRepo
cd TrainingRepo

git init
git remote add origin git@github.com:<organization>/TrainingRepo.git
```

---

## 3. Docker コンテナの起動

> **注意：** この時点では Laravel がインストールされていないため laravel コンテナはエラーで起動しません。mysql・minio・python のみ起動します。

```bash
docker-compose up -d mysql minio python
```

---

## 4. Laravel のインストール

```bash
# laravel コンテナをシェルで起動
docker-compose run --rm laravel sh

# 一時ディレクトリに Laravel をインストール（空でないエラーを回避）
composer create-project laravel/laravel /tmp/laravel
cp -r /tmp/laravel/. /var/www/
rm -rf /tmp/laravel

# Breeze インストール（React + Inertia.js + TypeScript スタック）
composer require laravel/breeze --dev
php artisan breeze:install react --typescript

exit
```

---

## 5. npm パッケージを Vite 8 対応バージョンに更新

Breeze インストール時に古いバージョンが入るパッケージを更新します。

```bash
docker-compose run --rm laravel sh

# @vitejs/plugin-react を Vite 8 対応バージョンに更新
npm install @vitejs/plugin-react@latest --save-dev

# @types/node を Vite 8 が要求するバージョンに更新
npm install @types/node@latest --save-dev

exit
```

---

## 6. axios を安全なバージョンでインストール

axios はサプライチェーン攻撃（2026年3月）と SSRF 脆弱性（CVE-2026-40175）の影響を受けています。

```bash
docker-compose run --rm laravel sh
npm install axios@1.15.0 --save
exit
```

---

## 7. bootstrap.ts の作成

```bash
cat > laravel/resources/js/bootstrap.ts << 'EOF'
import axios from 'axios';
window.axios = axios;
window.axios.defaults.headers.common['X-Requested-With'] = 'XMLHttpRequest';
EOF
```

---

## 8. vite.config.ts の確認

ZIP に含まれる `laravel/vite.config.ts` で Breeze が生成したファイルが上書きされているか確認します。

```bash
cat laravel/vite.config.ts
# server: { host: '0.0.0.0', port: 5173 } が含まれていれば OK
```

---

## 9. /register ルートの無効化

`laravel/routes/auth.php` を開き、以下の行をコメントアウトします。

```php
// Route::post('/register', [RegisteredUserController::class, 'store']);
```

---

## 10. 環境変数の設定

```bash
cp laravel/.env.example laravel/.env
cp python/.env.example python/.env
```

---

## 11. 全コンテナの起動

```bash
docker-compose up -d
```

---

## 12. アプリケーションキーの生成とマイグレーション

```bash
docker exec -it trainingrepo-laravel-1 sh
php artisan key:generate
php artisan migrate
php artisan db:seed
exit
```

---

## 13. Vite 開発サーバーの起動

別ターミナルで実行してください。

```bash
docker exec -it trainingrepo-laravel-1 sh
npm run dev
```

---

## 14. MinIO（S3 ローカル環境）の初期設定

1. ブラウザで `http://localhost:9001` を開く
2. ログイン情報を入力
   - ユーザー名：`minio`
   - パスワード：`minio123`
3. `Buckets` → `Create Bucket` → バケット名 `ses-matching` で作成
