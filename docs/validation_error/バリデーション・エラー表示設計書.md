# バリデーション・エラー表示設計書

> 最終更新：2026-05-06

## 概要
- 本ドキュメントは全機能共通のバリデーションおよびエラー表示仕様を定義する
- バリデーションは Laravel（FormRequest）で実装する
- エラーは Inertia.js を通じて Props としてフロントへ渡す

## 共通仕様

### エラー構造（Inertia）
```
errors.name
errors.skills.0.skill_id
errors.skills.0.experience_years
errors.phases.requirement_definition
```

### Props構造
| フィールド | 型 | 説明 |
| -------------- | -------- | ---------- |
| errors | object | バリデーションエラー |
| errors.{field} | string[] | エラーメッセージ |

### エラー表示ルール（UI）
| 項目 | 内容 |
| ------- | ------------ |
| 表示位置 | 入力項目の直下 |
| 表示件数 | 各フィールドごとに先頭1件を表示 |
| 表示タイミング | submit後 |
| スクロール | 最初のエラーへスクロール |
| 表示形式 | 赤文字表示 |

### エラーメッセージ方針
- 日本語で表示する
- 項目名＋エラー内容の形式とする
- 丁寧語で統一する（〜してください）
- フィールド単位でエラーを表示する
- エラーメッセージはLaravelのlangファイルで管理する

## 2. 人材管理（Engineer）

### 対象画面
| 画面 | URL | メソッド |
| ---- | -------------------- | ---- |
| 人材登録 | /engineers/create | POST |
| 人材編集 | /engineers/{id}/edit | PUT |

### バリデーション定義

#### 基本情報
| フィールド | バリデーション | エラーメッセージ例 |
| -------------- | ---------------- | -------------- |
| name | required | 氏名は必須です |
| name_kana | required / regex | カナで入力してください |
| birth_date | required / date | 正しい日付を入力してください |
| available_date | required / date | 稼働可能日を入力してください |
| nearest_station_id | required / exists | 正しい駅を選択してください |
| route_id | required / exists | 正しい路線を選択してください |

#### スキル情報
| フィールド | バリデーション | エラーメッセージ例 |
| ------------------------- | -------------------------- | ----------------- |
| skills | required / array / min:1 | スキルは1件以上登録してください |
| skills.*.skill_id | required / exists | スキルを選択してください |
| skills.*.experience_years | required / integer / min:0 | 経験年数は0以上で入力してください |
| phases | required / array / custom:at_least_one_true | 工程経験を選択してください |
| phases.* | boolean | 不正な値です |
| client_communication_experience | required / boolean | 選択してください |

#### 経歴・PR
| フィールド | バリデーション | エラーメッセージ例 |
| ------------------------- | -------------------------- | ----------------- |
| self_promotion | string / max:1000 | 1000文字以内で入力してください |
| resume_file | file / mimes:pdf / max:10240 | PDF（10MB以内）でアップロードしてください |

#### 希望条件
| フィールド | バリデーション | エラーメッセージ例 |
| ------------------------- | -------------------------- | ----------------- |
| desired_monthly_rate | integer / min:0 | 正しい金額を入力してください |
| work_types | array | 勤務形態を選択してください |
| work_types.* | string / in | 正しい勤務形態を選択してください |
| notes | string / max:1000 | 1000文字以内で入力してください |

#### 管理情報
| フィールド | バリデーション | エラーメッセージ例 |
| ------------------------- | -------------------------- | ----------------- |
| status_id | required / exists | ステータスを選択してください |
| main_user_id | required / exists | 主担当を選択してください |
| sub_user_id | nullable / exists / different | 主担当と異なるユーザーを選択してください |

### 更新時のバリデーション方針
| 項目 | 内容 |
| ----------- | ------------------------- |
| 基本ルール | 入力された項目のみ検証（sometimes） |
| skills | 配列が送られた場合のみ検証 |
| phases | 配列が送られた場合のみ「1つ以上true」チェック |
| sub_user_id | main_user_idと異なること |
