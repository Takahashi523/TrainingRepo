✅ v1.1 変更点（差分レポート適用）
  • [QA #77] システム名を「Nexus」に統一
  • [QA #76] サイドナビのロゴマーク削除・「Nexus」テキストのみ表示
  • [QA #80] 商流「プライム（エンド直）」→「プライム」に統一・TBD解除
  • [QA #79] ステータスのTBDラベル削除（選択肢：募集中 / 終了 / ペンディング確定）
🔴 維持TBD
  • ヘッダーstickyが正しく実装された場合、フォーム下部の保存・キャンセルボタンは不要になる可能性あり。実装時に判断すること
✅ 確定済み仕様
  • 勤務地：フリーテキスト確定。フルリモート・未選択時は行を非表示。画面上（稼働形態の切替時）は値をクリアせず、送信時にフロントで一次null化・保存時にバックエンド（ProjectService）が再度null化して最終保証する二段構え（QA #59 / Issue #50レビュー対応で記述訂正）
  • [Issue #50] 勤務地は「勤務地（最寄駅）」「勤務地（路線名）」の別行・別バッジ表示。最寄駅は常時必須（業務ルール固定）、路線名はマスタ設定（form_field_settings.work_location）に連動
  • 単価：スキル見合いチェックボックスあり。ON時に数値欄→テキスト入力へ切替（QA #14）
  • 稼働環境：フリーテキストでスキル要件セクション末尾に追加（QA #67）
  • 精算幅：フリーテキストで独立追加（QA #66）。【2026-08-26 修正】就業条件セクション → 契約条件セクション（単価の直後）へ移設　背景：「就業条件」の中身が精算幅・特記事項の2項目だけで、独立セクションとしてのまとまりが弱かった（issue #43）。理由：精算幅は「80万円 / 140〜180h」と単価とセットで意味を成す取引条件のため、単価の直後に置き、性質の異なる商流を間に挟まない
  • 【2026-08-26 修正】セクション再編（issue #43）：面談回数を勤務条件 → 基本情報（募集人数の後）、特記事項を就業条件 → 勤務条件（末尾）へ移設し、空になった「就業条件」セクションを削除。背景：面談回数は選考プロセスの属性で、勤務地・稼働形態（働く場所・形態）とは性質が違うのに勤務条件に置かれていた。理由：基本情報を「募集人数 → 面談回数 → 参画開始時期」の時系列にそろえ、面談回数1項目のために「選考プロセス」セクションを新設するのは過剰と判断した。案件詳細（WF_08）・マスタ管理のフォーム設定一覧（WF_12）も同じ順序にそろえている。勤務地2行の必須条件（issue #50）には変更なし
  • スキル：ラベル（最大15文字）＋詳細テキストエリア構成。ラベルは一覧・マッチング結果に表示
⚠️ WF_04（人材登録）との主な差分
  • スキルを「必須（年数あり）」と「尚可（年数なし）」に分離
  • 単価は下限〜上限の2フィールド横並び・非公開フラグなし
  • 勤務形態はチェックボックスではなくプルダウン（稼働形態）
  • 「業務内容詳細」テキストエリアを追加（AIマッチング用）
