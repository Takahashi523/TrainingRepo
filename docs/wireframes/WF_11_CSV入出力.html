📝 CSV作成のヒント
  • 「CSV UTF-8（コンマ区切り）」形式で保存してください（文字化け防止）。
  • カンマ・改行・引用符を含む項目は " "（ダブルクオート）で囲みます。
  • 空行（何も入力していない行）は無視されます。スペースだけの行は不正な行として扱われるので削除してください。
  • 一度にインポートできるのは 5,000 行までです。超える場合はファイルを分割してください。インポート中は完了までお待ちください。
  • 担当者ID（主担当ID / サブ担当ID）が分からない場合は右上の「担当者ID一覧」で確認できます。
  • エクスポートしたCSVには参照用に「主担当名 / サブ担当名」列が付きますが、取り込み時は無視され、担当者はID列で決まります。
  • ステータス・商流・稼働形態などは英字コードのまま入力してください（日本語で書き換えると取り込めません）。下の対応表を参照。
  • 日付は YYYY-MM-DD 形式で入力してください（例：2026-04-01）。Excel等 で開くと日付が別形式（2026/4/1 等）に自動変換されることがあり、その形式では取り込めません。ID列の数値が指数表記（1.2E+3）や先頭ゼロ落ちにならないようご注意ください。
  • CSV作業中は、対象の人材・案件を画面から編集しないでください。取り込み時に他の人の変更を上書きしてしまう場合があります。
コード対応： 人材ステータス＝ proposable提案可 / interviewing面談中 / not_proposable提案不可。 案件ステータス＝ open募集中 / closed終了 / pendingペンディング。 商流＝ primeプライム / secondary2次 / tertiary3次 / otherその他。 稼働形態＝ onsite常駐 / hybrid一部リモート可 / remoteフルリモート。 （0/1 で入力する項目：勤務形態フラグ・各工程経験・顧客折衝）

※ モーダル背景幕は明色ブラー（プロジェクト既定）。行番号はCSVの先頭（ヘッダー行）を1行目として数える。 全行ロールバック方式のため部分成功件数は表示しない（成功0件・全取消）。エラーCSVのダウンロードは非対応。 モーダルを閉じても結果は保持し、上の結果バナーの「詳細を表示」で再オープンできる。
モーダルの閉じ方：エラー行コピー時の誤爆を防ぐためオーバーレイ外クリックでは閉じない（閉じるのは「閉じる」ボタン／✕／Esc のみ）。
結果のクリア：「閉じる／✕／Esc」は非表示のみ（保持）。結果を破棄するのは「新ファイル選択／ファイル取消」の時だけ。タブ（人材⇄案件）ごとに独立保持。「再インポート」専用ボタンは無く、修正ファイルを選び直して「インポート実行」する同一フロー。
ファイルの扱い：CSVはサーバーに保存しない。実行後は成功・失敗ともファイル選択をクリア（失敗時も結果バナーは保持）。ブラウザのFileは選択時点のスナップショットのため、修正後は選び直して再実行する。未選択時は「インポート実行」を非活性にする。
【issue #61】AI要約スキップ警告：人材CSVインポートで新規行・更新行のAI要約生成（同期・1件ずつ）が設定秒数（既定20秒）の時間予算を使い切ると、以降は要約生成をスキップして通常のインポート結果（成功バナー）を先に確定させる。スキップが1件でも発生した場合のみ、成功バナーの下に警告バナー（amber）を常設表示する。元々はトースト（flash.error）で通知していたが、同一タイミングで発火する成功トーストと同時表示数の制限により黙って消えてしまう不具合があったため、常設バナー方式に変更した。
