## 1. はじめに

### 1.1 本書の位置付け

「国内SES向け 人材・案件マッチングシステム Nexus」のインフラ基盤であるAWSの設計を記載したドキュメントである。

---

### 1.2 コスト最適化に伴う制約とリスク
本構成は「AWS無料枠の最大活用」を最優先しているため、以下の制約がある。

- **高可用性の欠如:** Single-AZ構成のため、AWSの障害発生時にサービスが停止する。
- **データ復旧不可:** RDSバックアップが無効化されているため、論理削除・誤操作時のデータ復旧は不可。
- **スケール限界:** 無料枠対象のインスタンス（t3.micro等）を使用するため、同時アクセス数が増えた場合はパフォーマンス劣化の可能性がある。

## 4. ALB

### 4.1 ALB基本設定

| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **ロードバランサー名** | `Nexus-alb` | 識別用の固有名称。 |
| **スキーム (Scheme)** | `インターネット向け (Internet-facing)` | 外部ブラウザからアクセスさせるためパブリック属性にします。 |
| **IP アドレスタイプ** | `IPv4` | 研修環境のためIPv4のみで構成。 |
| **VPC** | `Nexus-vpc` | 前章で作成した研修用VPCを選択。 |
| **マッピング (サブネット)** | `Nexus-pub-sub` (AZ-a) | **必ずパブリックサブネットを指定**します。<br>※AWSの仕様上、ALB作成時は2つ以上のAZ選択を求められる場合があるため、その際は予備としてもう1つのAZのパブリック（またはプライベート）を仮選択します（通信はシングルAZで完結します）。 |
| **セキュリティグループ** | `Nexus-alb-sg` | インターネットからの `HTTPS (443)` 通信を許可したSGを新規作成して割り当てます。 |

### 4.2 リスナーとルーティング

| 設定項目 | 設定値 | 備考 |
| :--- | :--- | :--- |
| **プロトコル : ポート** | `HTTPS` : `443` | 受講生のブラウザからの安全なアクセスを受け付けます。 |
| **デフォルトアクション** | `ターゲットグループへ転送` | 後述のターゲットグループ（LaravelのNginx宛）を指定します。 |
| **安全なリスナー設定** | `デフォルトのSSL/TLS証明書` | **ACM (AWS Certificate Manager)** で事前に取得した研修用ドメインの証明書を選択します。 |

> 💡 **研修向けの補足（HTTP 80番の扱い）**
> 今回は最小構成のため「HTTPS (443)」のみを定義しています。「http://~」でアクセスされた場合に自動で「https://~」にリダイレクトさせたい場合は、追加で「HTTP:80 ➔ HTTPS:443へのリダイレクト」のリスナー設定を1行追加しますが、構築手順を最もシンプルにする場合は443番のみで問題ありません。

### 4.3 ターゲットグループ設定
ALBに届いた通信を、裏側にいるECSコンテナへ届けるための設定です（ECSサービスを作成する前に先につくっておきます）。

| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **ターゲットタイプ** | `IP` | **重要:** ECS Fargateを利用するため、ターゲットタイプは必ず「IP」を選択します。 |
| **ターゲットグループ名**| `Nexus-tg-laravel` | ターゲットグループの識別名。 |
| **プロトコル : ポート** | `HTTP` : `80` | ALBがSSLを解除（SSL終端）した後、コンテナ（Nginx）へは**未暗号化のHTTP(80番)**で通信を流します。 |
| **VPC** | `Nexus-vpc` | ターゲットが所属するVPCを指定。 |

### 4.4 ヘルスチェック設定
ALBがコンテナの生存確認を行うための最小設定です。

| 設定項目 | 推奨設定値 | 備考 |
| :--- | :--- | :--- |
| **ヘルスチェックプロトコル**| `HTTP` | 暗号化なしのHTTPでチェックします。 |
| **ヘルスチェックパス** | `/` または `/api/health` | Laravel側で200 OKを返せる軽量なパスを指定します。 |
| **正常しきい値** | `2回` | 研修中のデプロイ待ち時間を減らすため、最小回数に設定。 |
| **非正常しきい値** | `2回` | 異常を素早く検知するため最小回数に設定。 |
| **タイムアウト** | `5秒` | 応答を待つ制限時間。 |
| **間隔 (Interval)** | `10秒` | チェックを行う周期。研修用なので短めに設定。 |

### 4.5 ALB用セキュリティグループ設計

インターネットからのWebアクセス（HTTPS）をすべて受け付け、裏側のプライベートサブネット（ECSコンテナ）へ通信を受け渡すための制御設定です。

#### インバウンドルール
| 優先度 / 順序 | タイプ | プロトコル | ポート範囲 | ソース (送信元) | 備考 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | HTTPS | TCP | `443` | `0.0.0.0/0` (Anywhere) | インターネット全体からのWebアクセスをすべて許可。 |

#### アウトバウンドルール
| 優先度 / 順序 | タイプ | プロトコル | ポート範囲 | 送信先 (宛先) | 備考 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | すべてのトラフィック | すべて | すべて | `0.0.0.0/0` (Anywhere) | AWSのデフォルト設定（すべての通信を外へ流す）のままでOK。 |

## 5. 計算基盤 (ECS Fargate) - Laravel環境設計

研修環境におけるWebアプリケーション（Laravel + Nginx）を、サーバーレスコンテナ環境（AWS Fargate）で稼働させるための最小限の設定パラメータです。

### 5.1 タスク定義
コンテナの「設計図」となる設定です。AWSコンソールの「Amazon ECS」＞「タスク定義の作成」画面で使用します。

#### タスク・インフラストラクチャ設定
| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **タスク定義ファミリー名** | `Nexus-task-laravel` | タスク定義の識別名。 |
| **起動タイプ** | `AWS Fargate` | サーバー管理が不要なサーバーレスコンテナを指定。 |
| **オペレーティングシステム** | `Linux/X86_64` | 標準的なLinux環境。 |
| **タスクCPU** | `0.25 vCPU` (最少) | 研修用のため、無料枠・低コストの最小スペック。 |
| **タスクメモリ** | `0.5 GB` (最少) | 研修用のため、無料枠・低コストの最小スペック。 |
| **タスクロール** | `なし` (またはデフォルト) | Bedrockへのアクセスが必要になった際に設定。 |
| **タスク実行ロール** | `ecsTaskExecutionRole` | ECRからのイメージプルやCloudWatchへのログ出力に必要な標準ロール（自動生成されるものでOK）。 |

#### ②コンテナ定義
タスク内で動かす具体的なコンテナの設定です（※研修の手順をシンプルにするため、NginxとPHPを1つにまとめたオールインワンイメージ、もしくは標準的な2コンテナ構成のいずれにも対応できるようにポートを設定します）。

| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **コンテナ名** | `laravel-app` | コンテナの識別名。 |
| **イメージURI** | `[AWSアカウントID].dkr.ecr.[リージョン].amazonaws.com/nexus-laravel:latest` | 事前に **Amazon ECR** にプッシュしたDockerイメージのURIを指定。 |
| **コンテナポートマッピング**| `80` / `TCP` | ALB（ターゲットグループ）からの通信を受けるため、**ポート80番**を開放します。 |
| **環境変数 (Environment)** | `APP_ENV=local`<br>`DB_HOST=Nexus-rdsの動的エンドポイント` | Laravelがデータベース等に接続するための環境変数をここで注入します。 |
| **ログ収集 (Log collection)**| `オン (AWSLogs)` | CloudWatch Logsにコンテナのエラーログ等を出力させるため有効にします。 |

### 5.2 ECS Service定義
上記で作った「タスク（設計図）」を、実際にネットワーク上でいくつ稼働させるかを決める設定です。

#### デプロイ設定
| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **アプリケーションタイプ** | `サービス` | 常時起動させるWebアプリのため「サービス」を選択。 |
| **タスク定義ファミリー** | `Nexus-task-laravel` | 5.1 で作成したタスク定義を指定。 |
| **リビジョン** | `LATEST` | 常に最新のタスク設計図を使用。 |
| **サービス名** | `Nexus-service-laravel`| サービスの識別名。 |
| **サービスタイプ** | `レプリカ` | 通常のWebアプリケーション構成。 |
| **必要なタスク数** | `1` | 研修環境（Single-AZ）のため、コストを抑えて**「1」**に設定します。 |

#### ネットワーキング設定
コンテナをどのネットワーク空間に配置するかを設定します。

| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **VPC** | `Nexus-vpc` | 作成済みの研修用VPCを選択。 |
| **サブネット** | `Nexus-pri-sub` | **重要:** セキュリティのため、必ず**プライベートサブネット**を選択します。 |
| **セキュリティグループ** | `Nexus-ecs-sg` | 新規作成。インバウンドルールで「ALBのSG（`Nexus-alb-sg`）からのポート80番」のみを許可します。 |
| **パブリック IP の自動割当**| `無効 (DISABLED)` | プライベートサブネット配置のため不要（※ただし、NATゲートウェイがない環境でECRからイメージをプルする場合は一時的にパブリックサブネット＋有効にする等の研修環境に応じた微調整が必要です）。 |

#### ロードバランシング設定
作成したALBとECSサービスを紐付ける、最も重要な設定です。

| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **ロードバランサータイプ** | `Application Load Balancer` | 作成済みのALBを使用します。 |
| **ロードバランサーの選択** | `Nexus-alb` | 前章で作成したALBを指定。 |
| **プロダクションリスナーポート**| `443:HTTPS` | ALB側で待ち受けている443番のリスナーを選択。 |
| **ターゲットグループ名** | `Nexus-tg-laravel` | 前章で作成したターゲットグループ（ポート80宛）を指定。 |

| **パブリック IP の自動割当**| `無効 (DISABLED)` | プライベートサブネット配置のため不要。 |

> ⚠️ **ロードバランサー設定についての注意（研修向け重要ポイント）**
> 今回のPython AI Engineは、インターネット（外部）から直接アクセスされるものではなく、**プライベートサブネット内でLaravelから直接内部通信（`http://[PythonのプライベートIP]:8000`）で呼び出される仕組み**です。
> そのため、このECSサービス作成画面での「ロードバランシング (Load balancing)」設定は **`なし (None)`** を選択して構築します。

## 7. データ層 (RDS) - データベース設計

研修環境におけるユーザー情報や案件データを管理するため、リレーショナルデータベース（Amazon RDS MySQL）を最小構成かつコスト最適化（無料枠の範囲）で構築するための設定パラメータです。

### 7.1 データベース作成設定
AWSコンソールの「Amazon RDS」＞「データベースの作成」画面で使用する値です。

#### ① 標準設定・エンジンオプション
| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **データベース作成方法** | `標準作成` | すべてのパラメータを手動で確認・設定するため「標準作成」を選択。 |
| **エンジンのタイプ** | `MySQL` | 使用するデータベースエンジン。 |
| **エディション** | `MySQL Community` | 標準的なオープンソース版。 |
| **バージョン** | `MySQL 8.0.x` (推奨の最新安定版) | アプリケーション（Laravel）側の要求バージョンに合わせます。 |
| **テンプレート** | `無料利用枠 (Free Tier)` | **最重要:** 課金を防ぐため、必ず「無料利用枠」を選択します。 |

#### ② インスタンス・認証設定
| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **DB インスタンス識別子**| `Nexus-rds` | RDSインスタンス自体の名前（AWS上の識別名）。 |
| **マスターユーザー名** | `root` (または `admin`) | データベースの管理者ユーザー名。 |
| **マスターパスワード** | `任意の強力なパスワード` | Laravelの `.env`（環境変数）に設定するものと同じ値を指定。 |

#### ③ インフラ・ストレージ設定
| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **DB インスタンスクラス** | `db.t3.micro` (または `db.t4g.micro`) | 無料枠対象の最小スペックインスタンス。 |
| **ストレージタイプ** | `汎用 SSD (gp3)` | 標準的なストレージ。 |
| **割り当てストレージ** | `20 GiB` (最少) | 無料枠でカバーされる最大サイズ（20GiB以下）。 |
| **ストレージ自動スケーリング**| `無効 (チェックを外す)` | 研修環境で予期せぬ自動拡張による課金を防ぐためオフにします。 |
| **可用性と耐久性** | `マルチAZ配置しない` | 研修環境（Single-AZ）のため、自動でグレーアウトまたは「配置しない」になります。 |

#### ④ 接続
| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **VPC** | `Nexus-vpc` | 作成済みの研修用VPCを選択。 |
| **パブリックアクセス** | `なし (No)` | **重要:** セキュリティのため、インターネットからの直接接続を遮断します。 |
| **VPC セキュリティグループ**| `Nexus-rds-sg` | 新規作成。インバウンドルールで「LaravelのSG（`Nexus-ecs-sg`）からのポート3306番」のみを許可します。 |
| **アベイラビリティゾーン** | `ap-northeast-1a` (AZ-a) | ECSコンテナと同じAZを選択して、低レイテンシー（高速通信）にします。 |

#### ⑤ 追加の設定
画面最下部にある、隠れている折りたたみメニューを開いて設定します。

| 設定項目 | 推奨設定値 | 備考 / 設定のポイント |
| :--- | :--- | :--- |
| **最初のデータベース名** | `nexus_db` | 空欄にするとデータベース自体が作成されないため、必ずLaravel側が認識する初期スキーマ名を指定します。 |
| **自動バックアップ** | `無効 (チェックを外す)` | 研修環境のコスト最適化（スナップショット保存容量の節約）のためオフにします。 |
| **暗号化** | `無効` | 研修用のため、不要なパフォーマンス負荷や管理コストを避けるためオフ（またはデフォルトのまま）。 |

## 9. データフロー・通信経路一覧

各コンポーネント間の具体的な通信経路およびプロトコルは以下の通りです。

| 送信元 | 送信先 | プロトコル/通信方式 | 内容 |
| :--- | :--- | :--- | :--- |
| 営業担当者 (PCブラウザ) | ALB | HTTPS (443) | システムへの外部アクセス |
| ALB | Nginx | HTTP (復号済み) | リクエストのルーティング / ヘルスチェック |
| Nginx | PHP-FPM (Laravel + Inertia.js) | PHP転送 | Webアプリケーション処理の委譲 |
| PHP-FPM (Laravel + Inertia.js) | RDS (MySQL) | SQL | データベースへのクエリ発行（参照・更新） |
| PHP-FPM (Laravel + Inertia.js) | Uvicorn (FastAPI) | HTTP (同期通信) | AI処理（職務経歴書要約・推薦理由生成）の同期呼び出し |
| Uvicorn (FastAPI) | Bedrock | LLM API呼び出し | 外部LLMサービス（Amazon Bedrock）の利用 |
| Uvicorn (FastAPI) | Google Maps API | HTTPS (外部APIコール) | Distance Matrix APIを利用した経路・距離情報の取得 |
| ECR (Elastic Container Registry) | ECS Service - Laravel | イメージpull | Dockerコンテナイメージの取得（デプロイ時） |
| ECR (Elastic Container Registry) | ECS Service - Python AI Engine | イメージpull | Dockerコンテナイメージの取得（デプロイ時） |
