# 環境構築手順書

> 対象者：開発メンバー全員  
> 前提：リポジトリの初期セットアップが完了済みであること

---

## 前提条件

以下の2つのみホスト OS にインストールしてください。  
それ以外（Node.js・PHP・Python 等）は**一切インストール不要**です。

| ツール | 用途 | インストール先 |
|---|---|---|
| Docker Desktop | コンテナ実行基盤 | https://www.docker.com/products/docker-desktop/ |
| VS Code | エディタ | https://code.visualstudio.com/ |

### VS Code 拡張機能のインストール

VS Code を起動し、以下の拡張機能をインストールしてください。

- **Dev Containers**（`ms-vscode-remote.remote-containers`）

---

## 1. リポジトリのクローン

```bash
git clone git@github.com:<organization>/TrainingRepo.git
```

---

## 2. VS Code でフォルダを開く

> **注意：** ファイルを直接開くのではなく、**フォルダ単位**で開いてください。

1. VS Code のメニューから `ファイル` → `フォルダを開く`
2. クローンした `TrainingRepo/` フォルダを選択

---

## 3. Dev Container の起動

1. フォルダを開くと右下に以下のポップアップが表示されます

```
「コンテナーで再度開く」
```

2. `コンテナーで再度開く` をクリック
3. コンテナのビルドが自動で始まります

> **初回は10〜20分程度かかります。** 2回目以降はキャッシュが効くため1〜2分で起動します。  
> ポップアップが表示されない場合は、左下の `><` アイコン → `コンテナーで再度開く` を手動で選択してください。

---

## 4. チーム別 コンテナ起動方法

担当チームに応じて起動するサービスを選択してください。

### Laravel チーム

Laravel・MySQL・MinIO のみ起動します。Python コンテナは不要です。

```bash
# laravel/ ディレクトリで実行
cd laravel
docker-compose up -d
```

| 起動サービス | 用途 |
|---|---|
| laravel | Laravel + React（Inertia.js）|
| mysql | データベース |
| minio | S3 ローカル代替 |

### Python チーム

Python コンテナのみ起動します。

```bash
# python/ ディレクトリで実行
cd python
docker-compose up -d
```

| 起動サービス | 用途 |
|---|---|
| python | FastAPI マッチングエンジン |

### 全サービス統合起動（結合確認・統合テスト時）

Laravel・Python・MySQL・MinIO を一括起動します。

```bash
# リポジトリルートで実行
docker-compose up -d
```


```bash
php artisan migrate
php artisan db:seed
```

---

## 8. Vite 開発サーバーの起動

別ターミナルを開いて実行してください。

```bash
cd laravel
npm run dev
```

---

## 9. MinIO（S3 ローカル環境）の初期設定

> MinIO のデータは各自のローカル環境で完結します。メンバー間でのデータ共有は不要です。

1. ブラウザで `http://localhost:9001` を開く
2. ログイン情報を入力
   - ユーザー名：`minio`
   - パスワード：`minio123`
3. `Buckets` → `Create Bucket` → バケット名 `ses-matching` で作成

## 12. よくあるトラブルと対処法

### Dev Container が起動しない

フォルダ単位で開いているか確認してください。ファイルを直接開いている場合は `ファイル` → `フォルダを開く` で開き直してください。

### コンテナのログ確認

```bash
docker-compose logs laravel
docker-compose logs python
```

### マイグレーションが失敗する

```bash
php artisan migrate
```

### MinIO にファイルがアップロードできない

`laravel/.env` の以下が設定されているか確認してください。

```
AWS_USE_PATH_STYLE_ENDPOINT=true
```

## 13. よく使うコマンド

```bash
# マイグレーション
php artisan migrate

# キャッシュクリア
php artisan config:clear
php artisan cache:clear

# ルート一覧確認
php artisan route:list

# テスト実行（Laravel）
php artisan test

# テスト実行（Python）
cd /app && pytest
```

---

## 14. コンテナの停止

```bash
# 停止（データは保持）
docker-compose stop

# 停止 + コンテナ削除（データは保持）
docker-compose down

# 停止 + データも全削除（DB・MinIO のデータが消えます）
docker-compose down -v
```

> **注意：** `-v` オプションはローカルの DB・MinIO データが全て消えます。必要な場合のみ使用してください。

---

## 15. やり直す場合

```bash
# コンテナ・ボリュームを全削除
docker-compose down -v

# Git 管理外ファイルを全削除（vendor・node_modules 等）
git clean -fdx

# 手順4からやり直す
```
